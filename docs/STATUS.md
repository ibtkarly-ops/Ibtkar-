# حالة المشروع (آخر تحديث 2026-11-21)

## ما طُبّق فعلاً على Supabase الحيّ
- إصلاح قراءة الأسعار والبانر للزوّار (`is_admin()` لـ anon) ✅
- أسعار الباقات الافتراضية ✅
- برومتات جاهزة أغنى للمواقع (master / company / store / restaurant / landing) ✅
- Edge Function `ai-gateway` (النسخة 6): ربط مزود بمفتاح واحد + اكتشاف الموديلات + احتياط تلقائي + التحقق من كتلة `site-data` ✅

## ما عليك فعله أنت
1. **ارفع مجلد `public/` كاملاً (مع `vendor/`)** إلى Cloudflare بدل القديم.
2. من **الإدارة ← المحرك**: اختر المزوّد، الصق مفتاح API الصحيح، اضغط «ربط واكتشاف الموديلات».
   - المزودان القديمان (Claude و«ا») كان مفتاحاهما مرفوضين (401)؛ إن بقيا في القائمة احذفهما أو استبدل مفتاحيهما.
3. بعد ربط المزود: أنشئ موقعاً تجريبياً وتأكد أنه يخرج بتصميم الذكاء الاصطناعي لا القالب الأساسي.

## ما الجديد في الواجهة
- تصميم جديد كحلي + أزرق (فاتح افتراضياً + داكن)، مسطّح وسريع بلا تمويه ولا حركات ثقيلة.
- قائمة جانبية كلاسيكية (صفوف تحت بعض، الصف النشط مظلّل) تفتح من الجنب في الجوال وثابتة في الشاشات الكبيرة، وتعمل في الصفحات العامة أيضاً.
- صفحة رئيسية جديدة.
- إصلاح التعليق: لم يعد الموقع يتجمد عند تجديد الجلسة أو الرجوع للتبويب، وكل الطلبات لها مهلة، ومعالج الإنشاء ينتهي دائماً.
- مواقع كاملة (هيرو، من نحن، الأصناف، كيف تطلب، أسئلة شائعة، تواصل) بأصناف نموذجية بلا أسعار.
- تبويب **الأصناف** للعميل: يعدّل منتجاته/خدماته/قائمته ويحفظ وينشر بدون ذكاء اصطناعي.
- **التطبيقات**: «قريباً» + تسجيل اهتمام للعملاء والزوّار؛ للمدير العام معالج لإنشاء تطبيق ويب (PWA) بالذكاء الاصطناعي وقائمة المهتمين.
