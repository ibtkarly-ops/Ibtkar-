# صانع التطبيقات (Expo / React Native)

## من يستطيع استخدامه
- **المدير العام** دائماً.
- **مستخدمون تختارهم أنت:** الإدارة ← المستخدمون ← عمود «صانع التطبيقات» ← فعّل المربع بجانب المستخدم. (قاعدة البيانات ترفض تفعيله من أي حساب غير المدير العام.)
- بقية الزوار والعملاء يرون صفحة «قريباً» مع نموذج «أبلغني».

## كيف يعمل (مثل مبتكر)
1. **صف تطبيقك** في الشات. الذكاء يسأل سؤالاً واحداً فقط إذا كانت الفكرة غير مفهومة.
2. تظهر **بطاقة خطة**: الاسم، الأيقونة، الشاشات، الألوان، الميزات، وعدد الملفات ← زر **«ابدأ البناء»**.
3. يُكتب المشروع **ملفاً ملفاً** (شريط تقدّم)؛ كل ملف يُفحص (مكتبات مسموحة فقط، الاستيراد النسبي لملفات موجودة، بلا `eval`). ثم تُولَّد `index.js` و`app.json` و`package.json` و`eas.json` و`README.md` بالكود، وتُحفظ نسخة.
4. **Expo Go:** تبويب «Expo Go» ← «عرض في Expo Go» ← رمز QR. امسحه بكاميرا الجوال (بعد تنزيل Expo Go) فيفتح التطبيق. الرابط قصير ويولّد روابط ملفات جديدة كل مرة.
5. **الملفات:** شجرة الملفات + عارض الكود + «تنزيل المشروع (ZIP)».
6. **التعديل:** اكتب التعديل في الشات؛ يُعاد كتابة الملفات المعنية فقط ويُرفع رقم النسخة.

> الكود حقيقي وملك صاحبه، لكن يجب مراجعته واختباره قبل النشر؛ لا يوجد ضمان أنه خالٍ من الأخطاء أو أنه سيُقبل في المتاجر.

## البناء للمتاجر (EAS) — يحتاج إعداداً لمرة واحدة
الأزرار في تبويب «المتاجر» (للمدير العام فقط): **Android APK** للتجربة، **Google Play (AAB)**، **iOS / TestFlight**.

ما تفعله مرة واحدة:
1. **Expo:** أنشئ حساباً في expo.dev ← Access tokens ← أنشئ توكن.
2. **GitHub ← المستودع ← Settings ← Secrets and variables ← Actions**، أضف:
   - `EXPO_TOKEN` = توكن Expo.
   - `BUILD_SECRET` = نص عشوائي طويل (32 حرفاً أو أكثر) تختاره أنت.
3. **GitHub ← Settings ← Developer settings ← Fine-grained token** للمستودع نفسه بصلاحية **Actions: Read and write**.
4. **المنصة ← الإدارة ← الإعدادات ← «البناء التلقائي للتطبيقات»:** الصق توكن GitHub، ونفس `BUILD_SECRET`، واسم المستودع والفرع الذي فيه ملف `.github/workflows/eas-build.yml` (يجب أن يكون الملف في الفرع الافتراضي `main` حتى يقبل GitHub تشغيله). القيم تُحفظ مشفّرة في Vault ولا تظهر مرة أخرى.
5. **iOS:** يحتاج حساب Apple Developer مربوطاً بحساب Expo (`eas credentials` مرة واحدة)، و**Google Play** يحتاج حساب مطوّر لرفع ملف AAB.

بعد الضغط على زر البناء: يبدأ workflow في GitHub Actions، يجلب ملفات التطبيق من دالة `app-export` بالسر، يبني على EAS، ويُبلغ المنصة بالحالة ورابط التنزيل (يظهر في جدول «المتاجر»).
