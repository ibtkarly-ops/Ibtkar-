# ابتكار — نسخة PHP

واجهة PHP أخرى لنفس منصة ابتكار ونفس مشروع Supabase الحي (نفس البيانات،
نفس المستخدمين، نفس RLS). ليست منتجاً منفصلاً، بل بوابة دخول ثانية.

## ما يعمل فعلياً الآن (مبني ومُختبَر بـDocker حقيقي وطلبات REST حقيقية)

- الصفحة الرئيسية + الباقات (من جدول `plans` الحقيقي)
- تسجيل الدخول وإنشاء حساب (عبر Supabase Auth مباشرة)
- لوحة العميل: قائمة المواقع
- إنشاء موقع جديد: يستدعي **نفس** دالة `ai-gateway` (action=build) التي
  تبنيه بالذكاء الاصطناعي، وتنشره تلقائياً إن كان النشر مُهيّأً — تماماً
  كالواجهة الأصلية
- عرض موقع واحد ومعاينته (للمواقع من نوع HTML)
- إرسال طلب تعديل، وعرض حالة الطلبات
- الإشعارات

## ما لم يُنفَّذ عمداً في هذا الإصدار

- أي صفحة من لوحة الإدارة (المستخدمون، السيرفرات، مزودو AI، الباقات،
  البانرات، العقود، التذاكر، سجل المراجعة) — **لا شيء منها هنا إطلاقاً**
- الفواتير والعقود من جهة العميل
- قبول/رفض عرض سعر التعديل، تنفيذ التعديل نفسه (الموجود: الإرسال وعرض
  الحالة فقط)
- النطاقات المخصّصة، التحليلات، النسخ السابقة
- تبديل اللغة (عربي فقط هنا لتبسيط الإصدار الأول)
- أي تجديد تلقائي "صامت" متقدّم للتوكن (الموجود: إعادة محاولة واحدة فقط
  عبر refresh_token عند 401)

لو احتجت أي بند من هذه مُنفّذاً، أخبرني أيّها أولاً — هذا إصدار أول مقصود
أن يكون صغيراً ومُختبَراً حقاً بدل أن يكون كبيراً وغير مؤكد.

## التشغيل محلياً للتجربة

```bash
cd php-app
php -S 127.0.0.1:8088
# افتح http://127.0.0.1:8088/?p=home
```
