# ابتكار — هيكل Node.js (لغة ثانية للتوسّع لاحقاً)

**هذا ليس منفذاً كاملاً** — هيكل بداية فقط فيه الصفحة الرئيسية وتسجيل
الدخول، كمثال يُبيّن كيف تتصل بنفس Supabase من Node.js. أكمله لاحقاً باتباع
`../php-app/index.php` سطراً بسطر — نفس المسارات، نفس استدعاءات
Supabase، فقط بصياغة Node.js.

يستخدم فقط `http`/`https` المدمجتين في Node (بلا أي حزمة خارجية) حتى يبقى
الملف قابلاً للقراءة أثناء التوسّع فيه. إن احتجت إطار عمل (Express مثلاً)
لاحقاً، أضفه حين يكبر هذا الملف فعلاً.

## التشغيل محلياً

```bash
cd node-app
node server.js
# افتح http://127.0.0.1:3000/
```

مُختبَر فعلياً هنا (الصفحة الرئيسية، صفحة الدخول، 404) قبل كتابة هذا الملف.
