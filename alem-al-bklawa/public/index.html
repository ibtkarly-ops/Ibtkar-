الخادم غير متصل

هذا المتجر يحتاج إلى خادم ليعمل (Node.js، أو Cloudflare Workers مع قاعدة D1) لأن فيه قاعدة البيانات وواجهة الـ API. فتحه كملف مباشر أو رفعه على استضافة ملفات ثابتة لن يُظهر المنتجات ولا لوحة الإدارة.

  1. ثبّت Node.js 22 أو أحدث.
  2. من داخل مجلد المتجر شغّل: npm start
  3. افتح http://localhost:3000 (والإدارة على /admin).

للنشر على Cloudflare بلا سيرفر: npx wrangler@4 deploy، أو على سيرفرك: docker compose up -d --build (التفاصيل في README.md).
