الخادم غير متصل

هذا المتجر يحتاج إلى خادم Node.js ليعمل (قاعدة البيانات وواجهة الـ API). فتحه كملف مباشر أو رفعه على استضافة ملفات ثابتة لن يُظهر المنتجات ولا لوحة الإدارة.

  1. ثبّت Node.js 22 أو أحدث.
  2. من داخل مجلد المتجر شغّل: npm start
  3. افتح http://localhost:3000 (والإدارة على /admin).

للنشر: docker compose up -d --build أو أي استضافة تدعم Node.js (التفاصيل في README.md).
